# Vue 3 项目

这是一个使用 Vue 3 和 Vite 创建的最新版本项目，包含一个登录页面。

## 安装依赖

```bash
npm install
```

## 运行开发服务器

```bash
npm run dev
```

## 构建生产版本

```bash
npm run build
```

## 预览生产版本

```bash
npm run preview
```

## 项目结构

- `src/main.js` - 应用入口
- `src/App.vue` - 根组件
- `src/router/index.js` - 路由配置
- `src/views/Login.vue` - 登录页面

## 故障排除

- 确保 Node.js 版本 >= 16
- 如果遇到依赖问题，删除 `node_modules` 并重新运行 `npm install`
